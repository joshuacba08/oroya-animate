# v0.6.0 - Lighting, Textures & Transform Utilities

This release introduces major graphical enhancements and utility features to Oroya Animate, bridging the gap towards a more capable 3D engine.

## 🌟 New Features

### 💡 Lighting System
- **Light Component**: Added support for multiple light types.
  - `Directional`: Simulates sun-like infinite distance lighting.
  - `Point`: Omnidirectional light source with distance falloff.
  - `Ambient`: Base global illumination.
  - `Spot`: (Planned/Partial) Cone-shaped lighting.
- **Material Enhancements**:
  - Added `emissive` color and intensity.
  - Added `roughness` and `metalness` properties for PBR workflows.

### 🎨 Textures & Environment
- **Texture Mapping**: Support for diffuse maps, normal maps, roughness maps, and metalness maps (Three.js renderer).
- **Environment Component**:
  - Global `background` color control.
  - **Fog**: Exponential fog support (`color`, `density`) for depth cues.
  - Global `ambientLight` settings.

### 📐 Extended Geometry
- **New Primitives**:
  - `Cylinder`: Tunable radius (top/bottom), height, segments.
  - `Cone`: Built on cylinder logic.
  - `Plane`: Configurable width/height and segmentation.
  - `Torus`: (Partial/Core definition) Ring geometry.

### 🔄 Transform & Math Utilities
- **Transform Methods**:
  - `lookAt(target, up)`: Rotates object to face a target point (using Quaternion math).
  - `rotateOnAxis(axis, angle)`: Rotates object around a specific local axis.
  - `setFromMatrix(matrix)`: Decomposes a matrix into position, rotation, and scale.
- **Math Library**:
  - **Vector3**: Added `cross`, `dot`, `normalize`, `distanceTo`, `lerp`.
  - **Quaternion**: Added `slerp` (spherical linear interpolation), `lookAtQuaternion`, `setFromRotationMatrix`.

## 📚 Documentation & Examples
- **Web App**: Added new interactive examples in the Gallery.
  - **Textures & Environment**: Showcases PBR materials and fog.
  - **Transform: LookAt**: 'Predator-prey' demo showing objects tracking a moving target.
- **Tutorials**: (In progress) Landing page updated with new capability showcases.

## 🛠️ API Changes
- `Material` constructor now accepts `map`, `normalMap`, `roughnessMap`, `metalnessMap`.
- `Scene` graph now supports `Light` and `Environment` components officially.
- `Transform` is now more robust with dirty flag optimization for matrix updates.
